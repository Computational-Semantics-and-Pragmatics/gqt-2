# Generalized Quantifier Theory (Part 2) 

## Reading

* Rest of Kearns Chapter 6 (from 6.8 to the end)

## Task

You are given an incomplete `SmallWorld` project. Complete the semantic interpretations marked by `# EDIT THIS` comments. The aim is to be able to parse the test file `gq.test` and get the expected output given in `gq.out`.

In order to parse the test file do:
```
:pf gq.test
```
in the `SmallWorld` prompt.

Your output may be different from the one in `gq.out` due to your local settings but it must be equivalent to it, in the sense that you get the correct interpretations.

Please pull and install the latest version of `SmallWorld` before starting this task.
